# حمزاوي سات — Admin Panel v0.2

لوحة الأدمن متصلة فعليًا بـ Backend v0.2 عبر REST API.

## التشغيل
1. شغّل Backend v0.2 على المنفذ 3000.
2. شغّل لوحة الأدمن: `npm install` ثم `npm start`.
3. افتح `http://localhost:3001`.
4. سجّل دخول بحساب `admin` موجود في قاعدة البيانات.

عنوان الـAPI الافتراضي: `http://localhost:3000/api` ويمكن تغييره من LocalStorage بالمفتاح `hamzawy_api` إذا لزم.

## الوظائف المربوطة
- Dashboard حقيقي.
- الطلبات + سعر العميل + خصم الفني + النشر.
- اعتماد الفنيين.
- طلبات الشحن والموافقة/الرفض.
- بيانات محفظة الشحن.
- سجل معاملات الرصيد.
- JWT login للأدمن.

> ملاحظة: الـBackend يحتاج CORS في v0.2. تم تضمين التعديل في نسخة backend المرفقة.


## تدفق طلب العميل
العميل لا يحتاج حسابًا. يرسل الاسم والهاتف والخدمة والعنوان والمشكلة إلى `POST /api/orders`. يظهر الطلب في قسم طلبات العملاء بحالة `pending`. الأدمن يدخل سعر العميل وخصم الفني، ثم يحفظهما؛ عندها يتحول الطلب تلقائيًا إلى `available` ويظهر للفنيين. عند فتح الفني للطلب يتحول إلى `opened` ويُخصم الخصم من رصيده.
